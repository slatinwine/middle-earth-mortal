# 中土凡人 · 正在启程

本项目是「中土凡人」文字冒险游戏的启动引导页：以跃马客栈的炉火为引，3 秒倒计时后自动带你前往正式营地（官方站点）。

## ✨ 功能特性

- **自动启程**：3 秒倒计时结束自动跳转正式版，未跳转时可点击「进入中土」按钮手动前往
- **加载进度条**：与倒计时同步的金色加载条
- **中土风格视觉**：暗棕羊皮纸配色、符文装饰与衬线字体，营造中土世界氛围

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可看到引导页并自动跳转正式版（需要联网）。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript，零依赖、零构建、单文件
- `meta refresh` + JS `setTimeout` 双保险跳转，CSS keyframes 动画
